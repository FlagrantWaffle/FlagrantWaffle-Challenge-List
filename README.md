# FlagrantWaffle Challenge List

A Geometry Dash challenge list website for the FlagrantWaffle community.

## Features

- Ranked challenge list
- Waffle Points leaderboard
- Discord OAuth login
- Completion submissions
- Admin review system
- Discord notifications
- Player profiles
- Ranking management and changelog

## Tech Stack

- **FastAPI** backend web framework
- **Uvicorn** ASGI application server
- **PostgreSQL** relational database
- **Psycopg 3** PostgreSQL driver
- **Jinja2** server-side HTML templating
- **Docker Compose** container orchestration
- **nginx** reverse proxy
- **Cloudflare Tunnel** secure public access without direct port forwarding
- **Discord OAuth** user authentication
- **httpx** Discord API requests and bot notifications
